# 7Frames Portfolio

Aryan Rana's React 19, TypeScript, Vite, and Tailwind portfolio.

## Commands

```bash
npm ci
npm run dev
npm run lint
npm run build
npm run preview
```

Run `npm run refresh:videos` to refresh the three committed YouTube entries from the public channel feed.

## Content

- `src/data/content.ts` — profile, work, skills, contact, footer, and marquee data
- `src/data/blogPosts.ts` — blog articles
- `src/data/caseStudies.ts` — AMIZONE and financing-flow case studies

Vercel uses the build and single-page-app rewrite declared in `vercel.json`.
